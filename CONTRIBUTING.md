# Contributing

Thanks for helping! Bug reports, ideas and pull requests are welcome.

- **Bugs and ideas:** open an issue using one of the templates. Never paste your POESESSID or other secrets, and remove personal paths from logs.
- **Code:** see [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) for the repo layout, tests and the submodule workflow.
- **Changelog:** add a line under **Unreleased** in [CHANGELOG.md](CHANGELOG.md) for every user-facing change.
- **Ground rules:** every number must come from PoB's calculation, and the project never automates the game client or buying (see [SECURITY.md](SECURITY.md)).
- **Calculation or game-data bugs** that also happen in normal Path of Building belong upstream at [PathOfBuildingCommunity/PathOfBuilding](https://github.com/PathOfBuildingCommunity/PathOfBuilding/issues).
